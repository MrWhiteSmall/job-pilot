# 投递领航 · Job Pilot

已安装配套简历技能：[`resume-builder`](https://github.com/Jichengyuuuuu/resume-builder-skill)，入口位于 `C:\Users\lushengjie\.dsh\skills\resume-builder\SKILL.md`。这是第三方社区技能，安装时仓库约 181 stars，安装量未能验证；已审阅技能文本。它用于按 JD 优化简历，不负责浏览器投递。其 DOCX 输出依赖外部文档工具路径，Windows 上该输出链路尚未验证；本程序读取现有 PDF 不依赖它。

面向 BOSS 直聘的本地求职工作台。默认目标是 **杭州 / AI 应用开发与全栈 / 20–30K**。在本机保存简历、筛选规则、岗位、审核队列和沟通结果。

## 启动

在 PowerShell 中执行：

```powershell
Set-Location D:\DesktopCode\job-pilot
python -m pip install -r requirements.txt
python app.py
```

访问 <http://127.0.0.1:8765>。也可以双击 `启动投递领航.cmd`。服务仅绑定本机地址。

首次启动会读取用户指定的 PDF：`D:\DesktopDocuments\【简历】\简历20261105.pdf`。请在「简历」页核对解析结果；PDF 的日期和原始措辞不会被自动改写。若文件不存在，可在页面粘贴简历文本。

## 使用流程

1. 在页面核对简历与筛选条件。当前个人偏好：杭州、AI 应用开发/全栈、20–30K、公司 100–1000 人、社招、岗位要求硕士及以下。公司公布的规模区间需整体落在范围内，例如 100–499 人、500–999 人；1000–9999 人不算符合。博士要求、校招、应届或实习岗位排除；规模、招聘性质、学历或薪资无法确认时不会自动通过。
2. 点击「连接 BOSS」，使用本机已安装的 Chrome 打开专用资料目录与登录页。扫码时不连接 Playwright，也不自动登录。扫码成功后直接点击采集，程序通过仅限本机的浏览器调试连接复用同一窗口，无需手动关闭。该目录独立于日常 Chrome，不会自动包含日常浏览器的 Cookie。
3. 登录后点击采集；也可以导入 CSV 或 JSON。采集的是当前可见的真实列表，并尝试读取部分岗位的完整描述。未能获得完整要求的岗位会保留列表摘要标签。
4. 分析岗位，查看匹配理由和沟通草稿，审核有意向的岗位加入队列。
5. 先用「模拟」执行一轮，检查规则和队列。模拟不会触发外部沟通。
6. 确认后可切换真实模式、保存并开启托管。真实模式会对已审核且通过规则与分数门槛的岗位点击 BOSS「立即沟通」，遵守每日上限和执行间隔。
7. 受阻或结果不确定时，程序自动暂停托管；请查看日志与浏览器。不确定的结果不会自动重试，以免重复联系。

后台每 2 秒检查一次队列，每轮最多执行 1 个岗位；真实模式执行间隔最低 60 秒，每日额度按北京时间计数，包含受阻和结果不确定的尝试。模拟记录与真实额度分开，模拟后可继续对同一岗位执行真实沟通。暂停可阻止后续任务，已经发起的浏览器动作可能仍会完成。

可选开启「自动分析与审核」和「自动采集」。自动采集每 15 分钟尝试一次杭州岗位搜索；自动审核只会让通过硬条件、评分达标且有完整 JD 的岗位入队。AI 服务失败回退本地分析的结果需人工审核。默认关闭这两个选项，默认模拟且暂停，重启也会暂停。

**真实动作的范围：** 目前通过 BOSS 的「立即沟通」发起联系，使用平台设置的招呼语。页面确认成功后记录为已沟通。AI 草稿供检查和复制，程序不自动把草稿发进聊天，不自动发送 PDF 附件，也不会把点击行为记作附件已投递。其他平台暂未接入。没有登录完成后的实际页面验证之前，应保持模拟模式；适配器会在无法识别页面、登录或验证码阻挡时停止该项操作。

## AI 分析（可选）

不配置模型也能用本地硬条件和技能匹配。使用兼容 Chat Completions 的模型服务时，在启动前设置：

```powershell
$env:JOB_PILOT_API_KEY = '你的 API Key'
$env:JOB_PILOT_BASE_URL = 'https://你的服务商/v1'
$env:JOB_PILOT_MODEL = '你的模型名称'
python app.py
```

启用 AI 分析后，会将简历文本和待分析岗位描述发送到你配置的模型服务；请按需启用。密钥保留在进程环境中，不返回网页，不要把真实密钥写进仓库。模型负责分析与起草，执行队列由程序规则和人工审核控制。

## 导入格式

CSV 字段为 `title,company,city,salary,url,description`，UTF-8 编码。例如：

```csv
title,company,city,salary,url,description
AI应用开发工程师,示例公司,杭州,20-30K,https://www.zhipin.com/job_detail/EXAMPLE.html,Python LangGraph MCP Agent 应用开发
```

也支持包含上述字段的 JSON 数组。示例只是格式说明，导入前应换成真实岗位；程序不预置虚构岗位。

## 数据与维护

- 数据保存在本项目 `data/`（或后端配置的 SQLite 路径），浏览器登录保存在 `data/boss-chrome-profile/`。
- `.gitignore` 排除了数据库、会话、日志和环境配置。备份会话目录相当于备份登录信息，请仅在自己的设备保存。
- 重启后托管保持暂停，请核对队列再开启。
- BOSS 页面结构可能变化，无法识别时日志会说明原因。程序不绕过验证码或平台限制。
- 当前连接方式需要本机已安装的 Google Chrome。使用普通 Chrome 启动及 Playwright 官方 CDP 连接，不再使用带默认自动化参数的启动方式。
- 部分薪资采用自定义字体。无法可靠读出数字时薪资留空并标注待核验，该岗位不会通过薪资硬筛选，不猜测数字。

运行测试：

```powershell
python -m pip install pytest
python -m pytest -q
python verify_ui.py
python verify_flow.py
```

`verify_ui.py` 检查已启动服务的桌面与手机布局、简历加载；`verify_flow.py` 会另起隔离数据库与临时本地服务，验证导入、评分、审核和模拟执行，不会改动工作台中的真实岗位或联系雇主。
