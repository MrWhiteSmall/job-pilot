# 规则速查（按期望顺序生效）

## 硬条件（不满足直接淘汰，score = -1）

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `cities` | `["杭州"]` | 列表里的城市需包含关键字；采集器支持 杭州/上海/北京/深圳/广州/南京/苏州/成都/武汉/西安/合肥/宁波（`browser_adapter.CITY_CODES`） |
| `districts` | `["余杭","西湖","拱墅","滨江","萧山"]` | 只影响**排序**：靠前的区先投，未列出的排最后 |
| `titles` | `["AI应用","大模型应用","Agent","全栈"]` | 标题命中才保留，比较时忽略空格 |
| `exclude_titles` | `["产品经理","销售","讲师","总监"]` | 标题命中即淘汰（非研发岗） |
| `min_salary` / `max_salary` | `20` / `30` | 区间**有交集**才通过；`25-45K` 过，`8-12K`、`35-65K` 不过 |
| `company_min` / `company_max` | `100` / `999` | 公布区间需整体落在范围内；未公布则标待核验、不淘汰 |
| `tiny_needs_funding` | `false` | 开启后 0–20 人公司必须有融资证据（天使轮/A轮…/已上市）；`未融资`、`不需要融资` 算没有 |
| `large_needs_foreign` | `false` | 开启后 1000 人以上只准入外资/外企 |
| `foreign_whitelist` | 内置约 290 个外企品牌词 | 企业性质字段缺失时按公司名匹配；可整体覆盖，短英文名（≤4 字符）按词边界匹配 |
| `recruitment_type` | `"social"` | 排除校招/应届/在校/实习/兼职 |
| `max_education` | `"硕士"` | 要求博士的淘汰；`本科及以上` 按本科算 |
| `blacklist` | `["阿里巴巴","华为","外包"]` | 命中公司名即淘汰 |
| `dedupe_companies` | `true` | 关闭后不做公司级 30 天去重，只按岗位（URL / 已尝试记录）去重 |
| `allow_unknown_salary` | `false` | 开启后薪资抓不到也照常沟通，日志记 `salary_unknown` |

内置规则（无需配置）：

- 外包/驻场/派遣/劳务 且无「非外包 / 不驻场」澄清 → 淘汰；
- 同一公司 30 天内已沟通过 → 其它岗位跳过；
- 同一岗位 URL 去重；
- 非社招描述（`本岗位仅面向在校学生`）→ 淘汰，而 `负责指导实习生` 不影响。

## 打分与队列

- 本地分：`40 + 60 × min(1, 命中技能数 / 4)`；零命中 = 40 分。
- `min_score` 建议 55 以上，否则「什么岗都能过」。
- AI 分：模型输出 0–100 + 理由 + 风险 + 缺失技能；失败回退本地分并标记 `local_fallback`，这类**不自动审核**。
- 队列顺序：`(districts 次序, -score, id)`。

## 托管参数

| 字段 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | false | 重启强制 false |
| `mode` | `dry_run` / `live` | `dry_run` | dry_run 只记模拟，不碰浏览器 |
| `daily_limit` | 1–200 | 10 | 按北京时间统计，含 blocked/uncertain |
| `interval_seconds` | ≥10（dry）/ ≥60（live） | 90 | 两次尝试的最小间隔 |
| `min_score` | 0–100 | 60 | 低于此分不派发 |
| `auto_approve` | bool | false | 自动把达标且有完整 JD 的岗位入队 |
| `auto_collect` | bool | false | 每 10 分钟尝试采集一次 |
| `greeting` | ≤2000 字 | 空 | 留空只发平台招呼语；填了才补发第二条 |

## 采集参数

| 字段 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| `collect_titles` | ≤40 项 | 取 `titles` | 采集用关键词，与匹配用的 `titles` 分开 |
| `collect_pages` | 1–20 | 10 | 每个「关键词 × 城市」翻几页；页码游标存 `data/collect-cursor.json` |
| `collect_budget` | 30–1800 秒 | 200 | 单轮采集时间预算；超时靠 `app.start_supervisor` 兜底 |

## 状态含义

| 状态 | 含义 |
| --- | --- |
| `new` | 已采集，未分析 |
| `matched` | 通过硬筛且分数达标，待人审核 |
| `rejected` | 硬条件淘汰（看 `reason`） |
| `approved` | 已审核入队，等 worker 派发 |
| `sent` | 页面确认发起沟通成功 |
| `blocked` | 页面显示继续沟通 / 平台拦截（上限、验证） |
| `uncertain` | 点了但没拿到明确成功反馈，**不会自动重试** |
| `simulated` | 模拟模式记录，可再用真实模式投一次 |
